Version 1: Constrained least square fitting.
Version 2: Least square fitting using only independent variables.

The two versions solve the same problem. With the example data it is
underdetermined: 6 combinations of the 54 independent tensor elements do not
change any of the dipoles. Both versions therefore return the minimum-norm
solution and print a warning, and their results agree (to 1e-17).

The earlier Julia version 1 solved a singular KKT system, which added an
arbitrary null-space component; that is why the two versions used to disagree
while giving the same fitting errors. More spin configurations are needed to
determine every element.
